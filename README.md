# Neon Cargo Express

Ein Neon-Arcade-Lander für den Browser. Starte auf Plattform A, hol die Frachtkiste ab und setz sie sanft auf Plattform B ab. Mit dem verdienten Geld rüstest du in der Werft Tank, Schild und Triebwerk auf.

**Spielen:** https://janscharf265.github.io/neon-cargo-express/

## Auf dem iPhone installieren

1. Link oben in **Safari** öffnen.
2. **Teilen** → **Zum Home-Bildschirm**.
3. Das Spiel startet danach im Vollbild und läuft nach dem ersten Öffnen auch offline.

## Steuerung

| Aktion | Tastatur | Touch |
| --- | --- | --- |
| Haupttriebwerk | ↑ / W / Leertaste | Knopf rechts unten |
| Drehen | ← → / A D | Knöpfe links unten |
| Neu starten | R | Pause-Menü |
| Pause | P / Esc | Pause-Knopf |
| Ton | M | Ton-Knopf |

## Dateien

- `index.html` – das komplette Spiel (HTML, CSS, JavaScript in einer Datei)
- `manifest.webmanifest`, `icons/` – App-Name und Icons für den Home-Bildschirm
- `sw.js` – Offline-Speicher (bei Änderungen die Versionsnummer `CACHE` erhöhen)
